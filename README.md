# בונים חלום 🏠 (Dream House Builder)

משחק דפדפן לבניית בתים ועיצוב חללי הפנים שלהם – לילדים מגיל 9 ולמבוגרים שאוהבים לתכנן.

- **תכנון** – שרטוט חדרים וקירות במבט־על, עם מידות, שטחים והצמדות.
- **תלת־ממד** – הבית נבנה מעצמו; מסובבים, מרהטים וצובעים.
- **סיור בבית** – דמות שהולכת בחדרים, פותחת דלתות, מתיישבת על הספה ונשכבת במיטה.
- **שמירה** – אוטומטית בדפדפן, עם גיבוי לקובץ `.dreamhouse.json`.

## הרצה מקומית
```bash
npm install
npm run dev
```
ולפתוח את הכתובת שמודפסת (בדרך כלל http://localhost:5173).

## פקודות נוספות
```bash
npm test          # בדיקות יחידה
npm run build     # בדיקת טיפוסים + בנייה ל-dist/
npm run preview   # הגשת הגרסה הבנויה
```
